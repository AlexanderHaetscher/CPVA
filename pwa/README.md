# CPVA Startstreckenrechner als PWA

Die Anwendung ist eine rein lokale, offlinefähige PWA. Für die Installation auf einem Smartphone muss sie über HTTPS oder während der Entwicklung über `localhost` ausgeliefert werden.

## Lokal testen

Im Projektordner einen einfachen Webserver starten und anschließend `http://localhost:8765/pwa/` öffnen. Die PWA kann danach im Browser zum Startbildschirm hinzugefügt werden.

Die Berechnungsdaten liegen in `app.js`. Die Excel-Datei bleibt die Referenz für die Tabellenwerte.
